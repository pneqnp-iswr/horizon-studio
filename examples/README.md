# Examples

- `workshop_showcase.hstudio.json`: **0.4** showcase, with all six procedural generators, export rotation/mirror, two UI language names, tool tags and crafting.
- `workshop_showcase.hmod`: locally generated **experimental** content package, not verified by the official game/CLI.
- `ruby_demo.hstudio.json`: small item, block and recipes example.
- `voxel_showcase.hstudio.json`: previous 0.3 three-structure project.
- `voxel_showcase.hmod`: previous 0.3 unverified sample package.

Open `.hstudio.json` using **Open project** in the editor or build headlessly using `python horizon_cli.py build examples/workshop_showcase.hstudio.json`.

No proprietary game assets are bundled.
